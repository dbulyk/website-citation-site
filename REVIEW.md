# Site review

- Check the live form against the formatter inputs, including anonymous sources, partial publication dates, multiple authors and locator scope. Invalid data must clear the old result and disable Copy.
- Check that every successful copy of the current citation can reveal the inline install actions, including after Close and reload. Check failure, edits and dialog activation during a pending write. Verify focus on Copy and when dismissing the inline actions or a context dialog.
- Use the browser at the required viewport sizes to check first-fold actions and long values. Exercise the native disclosure with pointer, keyboard and reduced motion. Check the walkthrough steps, arrow placement, touch targets, focus and stable iframe height.
- Check relative asset and download links in the build and compare the uninstall output with its source byte-for-byte.
- Prefer existing code, then platform APIs, then a small addition. Confirm behavior through the site entry point. A screenshot proves appearance, while clipboard stubs exercise the app’s response to clipboard outcomes. Use a real clipboard run to verify the write.
