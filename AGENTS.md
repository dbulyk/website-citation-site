# Website Citation site

- Use `src/formatter.js` as the citation formatting boundary. Keep webpage metadata local to the page and render user text through DOM text or attributes. Only the formatter's sanitized HTML belongs in the result.
- Treat `uninstall/index.html` as the source of the preserved uninstall route. Use the Vite static copy when building.
- For website changes, follow the [verification skill](.cursor/skills/verify-citewebsite/SKILL.md). For review, use [REVIEW.md](REVIEW.md).
